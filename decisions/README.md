# Architecture Decision Records

Core MAMA framework decisions are recorded here as short ADRs. Format: **Context → Options → Decision → Consequences → Dissent/unresolved**. Each ADR is immutable once `reviewed`; superseding requires a new ADR that links back.

| ADR | Title | Status |
|---|---|---|
| [ADR-001](adr-001-mama-naming-and-relationship.md) | MAMA naming and the MAMA ↔ `mama` relationship | accepted (v0.1.0, draft artifact) |
| [ADR-002](adr-002-licensing.md) | Licensing: CC-BY-4.0 for definitions, Apache-2.0 for code | accepted (v0.1.0, draft artifact) |
| [ADR-003](adr-003-no-composite-score.md) | No composite MAMA score | accepted (v0.1.0, draft artifact) |

Propose a new ADR via a [Framework Proposal issue](https://github.com/Measuring-Automation-Managing-Autonomy/mama-framework/issues/new?template=framework-proposal.yml). Proposals sit open ≥7 days; dissent is recorded inside the ADR.
